# 工作台显示规范

适用 `vue-independent/` 的编辑器、属性面板、公共弹窗和预览工具栏。基于既有 Element Plus 组件、浅色蓝灰配色，以及通用前端字号约束，提取 Linear 参考中的间距与文字层级，不引入营销页的大字、暗色主题或装饰。

## 字体与尺寸

- 系统字体：macOS 系统字体、苹方、微软雅黑；控件正文与按钮 14px/22px，字重 400/500。
- 图元卡片说明等辅助文字 12px/18px；分组标题层级 16px，弹窗标题 18px/28px、600 字重。应用文字不低于 12px，采用偶数字号。
- 默认及紧凑控件高 32px；图标 16px，资源导航图标 24px、图元缩略图 40px。触屏预览按钮最小高 40px。
- 间距统一 4/8/12/16/24px：组内 8px、面板左右 16px、表单项间 16px、弹窗内边距 24px。
- 控件圆角 4px，浮动工具条和弹窗圆角 8px；正文 #263849，次要文字 #5b6b7c，边框 #dce4ed，浅底 #f5f7fa。

## 布局与状态

- 工具栏空间不足时按组换行，图标按钮保持尺寸；预览在 600px 以下将数据输入另起一行。
- 编辑器资源栏 280px、属性栏 320px；工作区保留 `min-height: 0`，面板内部滚动，工具栏不被长列表推出视口。
- 弹窗最大宽度为视口减去 32px，正文最大高度 70dvh 并独立滚动，底部操作始终可见。
- 保留 Element Plus 的焦点、禁用、加载状态；键盘聚焦按钮有清晰描边。
- 加载使用局部骨架，接口失败使用明确提示/重试，空数据使用空态。

## 实现入口与边界

统一变量在 `vue-independent/src/ui-tokens.less`；`styles.less` 导入，局部组件使用变量。应用控件不再靠逐页写死字号和压缩控件来适应宽度。

画布中的图元文字、线宽、尺寸、颜色和媒体样式属于用户保存的组态设计，继续读取画面 JSON。上述显示规范不重写这些业务配置，也不修改图元资源模板。
