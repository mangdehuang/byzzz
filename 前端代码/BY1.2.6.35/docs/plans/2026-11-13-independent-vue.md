# 组态前端独立化

1. 独立构建。新入口及资产目录不引用旧页面、旧脚本或旧 CSS。保留已发布的图元和模板数据，构建后只输出一份 HTML。
2. 场景引擎。通过 npm Konva 读取原场景格式，用可序列化节点驱动选择、拖放、布局、历史记录和属性更新。以 100 个基础图元和预设画面验证导入。
3. 界面与接口。使用 Vue 和 Element Plus 实现资源面板、图层树、属性配置、画布、通讯、设备、模板及图库，使用 Go 现有接口持久化。
4. 监控。单独实现 WebSocket、MQTT、动画规则、事件、媒体和图表。按原版行为逐项对照。
5. 切换。只有功能对照覆盖原能力后才替换当前默认编辑器。用缺少原 byzt 源码的构建和 Go 服务验证独立运行。
