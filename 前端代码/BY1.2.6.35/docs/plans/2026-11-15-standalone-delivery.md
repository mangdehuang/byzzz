# 新前端独立交付实施记录

目标：日常开发、构建、Go 托管和交付包都只使用新 Vue 前端，不依赖旧 byzt/、兼容版 vue/ 或旧 dist/。

1. 默认 Vite 配置统一导出独立配置，保留独立命令别名。
2. Go 默认定位 dist-independent/byzt；删除原版页面回退和旧目录环境项。用测试验证缺少入口、缺少配置均失败。
3. 白名单复制新前端与 Go 源码到临时目录，离线安装、运行测试和默认构建，检查单 HTML 与缺少旧运行时文件。
4. 用临时数据库启动隔离 Go，验证四类页面入口、静态资源、配置、画面保存重读和旧脚本 404。
5. 从隔离副本输出源码与已构建资源交付包，仅携带安全默认配置，不复制真实数据库和密钥。

实际服务联调和旧功能完整验收单独记录；构建独立性不替代功能等价证明。
